The project uses Git and GitHub as the primary source code management platform.

The following branching strategy is applied:

\begin{itemize}
    \item main: stable production-ready code
    \item develop: integration branch
    \item feature/*: feature development branches
    \item hotfix/*: urgent bug fixes
\end{itemize}

All code changes are committed using meaningful commit messages and reviewed through Pull Requests before merging into the main branch.

Code reviews help ensure code quality, maintainability, and consistency throughout the project.
