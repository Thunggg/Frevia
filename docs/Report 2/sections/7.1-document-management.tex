All project documents are maintained in a centralized repository using Google Drive and GitHub.

The managed documents include:

\begin{itemize}
    \item Project Management Plan (PMP)
    \item Software Requirements Specification (SRS)
    \item Software Design Specification (SDS)
    \item Test Cases and Test Reports
    \item User Manuals
    \item Meeting Minutes
\end{itemize}

Document versions are tracked using version numbers and update dates. Major modifications require review and approval before publication.

Obsolete versions are archived to maintain traceability and historical records.
