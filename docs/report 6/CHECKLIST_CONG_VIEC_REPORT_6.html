Hạng mục A1: Record of Changes & Deliverable Package (Section 1) Nhật Huy
A1.1Bảng Record of Changes
Ghi nhận lịch sử tạo mới (A) và cập nhật (M) của cả 5 thành viên theo từng đợt review.
A1.2Bảng Deliverable Package (II.1)
Liệt kê đầy đủ 12 hạng mục bàn giao: Schedule, Backlog, Monorepo Source Code, 2 AI Services, DB Migrations/Seeds, Docker files, Reports 1–7, Test Suites, Slide thuyết trình.
Hạng mục A2: System Requirements & Network Ports (Section 2.1) Nhật Huy
A2.1Yêu cầu phần cứng Client (Người dùng cuối)
CPU Dual-core+, RAM 4GB+, Webcam (chụp Selfie eKYC), Trình duyệt Chrome/Edge/Firefox/Safari.
A2.2Yêu cầu phần cứng Server / Máy chạy Docker
CPU 4-8 cores, RAM tối thiểu 16GB (chạy 5 containers đồng thời + Ollama LLM), SSD trống 25GB+.
A2.3Yêu cầu phần mềm nền tảng (Software Stack)
Windows 10/11 WSL2 / Ubuntu 22.04 LTS, Git, Node.js v22 LTS, PNPM v9+, Docker Desktop v26+, Python 3.11.
A2.4Bảng ánh xạ cổng mạng (Network & Port Mapping Table) Tiến Thuận
Web Frontend (3003/3001), Backend API (3002/3000), Postgres (5432), Redis (6379), Ollama (11434), AI CV-Matching (8000), AI ID-Verification (8001).
Hạng mục A3: Hướng dẫn cài đặt từ A đến Z từ máy trắng (Section 2.2) Chụp ảnh khoanh đỏ từng bước bấm
A3.1Bước 1: Cài đặt công cụ nền tảng (Prerequisites) Nhật Huy
Tải & cài Git, Node.js v22 LTS, PNPM, Docker Desktop (bật WSL2) và PostgreSQL/Redis. Chụp ảnh màn hình khoanh đỏ từng bước cài và lệnh kiểm tra version.
A3.2Bước 2: Clone Source Code & Cài đặt Dependencies Nhật Huy
Lệnh git clone, kiểm tra thư mục ai-services/, chạy pnpm install cho toàn bộ Monorepo.
A3.3Bước 3: Cấu hình biến môi trường (.env) Nhật Huy
Tạo apps/api/.env và apps/web/.env. Giải thích chi tiết Database, JWT, Google OAuth, Cloudinary, Stripe, SMTP, AI Endpoints.
A3.4Bước 4: Khởi tạo Database, Chạy Migration & Seed Nhật Huy
Prisma generate, migrate deploy, seed:permissions, seed:job-categories, seed. Bảng danh sách tài khoản Demo để đăng nhập thử ngay.
A3.5Bước 5: Khởi chạy toàn bộ hệ thống (Docker Compose & Local) Tiến Thuận
Chạy docker compose up -d --build (5 containers), lệnh kéo model ollama pull qwen3:4b, chụp ảnh Docker Desktop xanh Running. Hướng dẫn chạy local pnpm dev.
A3.6Bước 6: Kiểm tra vận hành sau cài đặt (Post-Installation Verification) Tiến Thuận
Truy cập Web (localhost:3003), Swagger API (localhost:3002/api), AI Swagger (localhost:8000/docs & 8001/docs).
