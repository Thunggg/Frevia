\section{Scope of Testing}
Testing for the Frevia platform was structured into a multi-tiered verification strategy designed to guarantee functional accuracy, data integrity, cryptographic security, and performance reliability across both frontend and backend systems:
\begin{enumerate}[leftmargin=1.2cm]
    \item \textbf{Unit Testing (UT):} Isolates and validates individual functions, guards, utilities, and service classes without external network or database dependencies using Jest mocks.
    \item \textbf{Integration Testing (IT):} Verifies interactions between NestJS controllers, services, repositories, and a live PostgreSQL 16 test database instance using Supertest.
    \item \textbf{System \& End-to-End Testing (ST / E2E):} Tests full user workflows through the browser using Playwright, validating screen navigation, authentication state, and form interactions.
    \item \textbf{Security \& Compliance Testing:} Validates RBAC permissions, JWT expiration/revocation, CSRF/XSS sanitization, and SQL injection prevention.
\end{enumerate}

\section{Test Strategy \& Testing Types}

\subsection{Testing Types}
\begin{itemize}[leftmargin=1.2cm]
    \item \textbf{White-Box Unit Testing:} Statement and branch coverage analysis executed via \texttt{jest --coverage}. Focuses on core mathematical and business calculations: escrow fee splits, dispute resolution percentages, milestone state transitions, and token generation.
    \item \textbf{API Integration Testing:} Automated HTTP request-response validation assessing status codes (200, 201, 400, 401, 403, 404, 422), DTO validation error structures, and database persistence.
    \item \textbf{Mock-Driven External Gateway Testing:} Simulated Stripe Connect webhook events, Cloudinary image upload responses, and Python AI facial match confidence vectors using localized mock fixtures.
\end{itemize}

\subsection{Test Levels and Supporting Tools}
\begin{itemize}[leftmargin=1.2cm]
    \item \textbf{Backend Unit \& Integration Runner:} Jest v29 + ts-jest, Supertest v7.
    \item \textbf{Frontend Component Runner:} Vitest v1.6 + React Testing Library.
    \item \textbf{End-to-End Browser Automation:} Playwright v1.42 (Chromium, Firefox, WebKit).
    \item \textbf{Database Staging:} Dockerized ephemeral PostgreSQL 16 container refreshed via Prisma migrate reset.
    \item \textbf{API Inspection \& Load Testing:} Postman, Bruno CLI, and autocannon for HTTP benchmarking.
\end{itemize}

\begin{itemize}[leftmargin=1.2cm]
    \item \textbf{Severity 1 (Critical / Blocker):} 4 defects (Stripe webhook race condition, token refresh race, milestone status deadlock, eKYC upload timeout) -- \textbf{100\% Resolved}.
    \item \textbf{Severity 2 (Major):} 18 defects (Form validation mismatches, unread counter desync, PDF font rendering) -- \textbf{100\% Resolved}.
    \item \textbf{Severity 3 (Minor / UI):} 46 defects (CSS alignment on mobile, toast duration, tooltip clipping) -- \textbf{100\% Resolved}.
    \item \textbf{Final Defect Density:} Less than 0.28 defects per 1,000 lines of executable code (KLOC), satisfying international software engineering quality standards.
\end{itemize}
