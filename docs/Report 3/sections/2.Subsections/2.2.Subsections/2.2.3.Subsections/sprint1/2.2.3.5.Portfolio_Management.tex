Description: & \multicolumn{3}{L{11.1cm}|}{Allows an authenticated freelancer to create a new portfolio entry, optionally uploading media files (images, documents, links).} \\ \hline
Preconditions: & \multicolumn{3}{L{11.1cm}|}{
\textbf{PRE-1} The freelancer is authenticated and logged in. \newline
\textbf{PRE-2} The freelancer is viewing their own portfolio management section.
} \\ \hline
Post-conditions: & \multicolumn{3}{L{11.1cm}|}{
\textbf{POST-1} A new portfolio record is created in the database. \newline

} \\ \hline
Normal Flow: & \multicolumn{3}{L{11.1cm}|}{
\textbf{A. Add New Portfolio} \newline
1. Freelancer clicks the ``Add Portfolio'' button. \newline
2. The system displays the Add Portfolio form. \newline
3. Freelancer enters portfolio details (title, description, role, technologies used). \newline
4. Freelancer optionally uploads media files or provides external links. \newline
5. Freelancer clicks the ``Save'' button. \newline
6. The system validates the input data and media file formats/sizes. \newline
7. The system uploads and stores the media files. \newline
8. The system creates a new portfolio record in the database. \newline
9. The system displays the message: ``Portfolio created successfully.'' \newline
10. The system redirects the freelancer to the updated portfolio list.
} \\ \hline
Alternative Flows: & \multicolumn{3}{L{11.1cm}|}{\textbf{A.5 Cancel Creation} \newline
1. Freelancer clicks the ``Cancel'' button. \newline
2. The system discards the input and any pending uploads. \newline
3. Return to step A.1.} \\ \hline
Exceptions: & \multicolumn{3}{L{11.1cm}|}{\textbf{EX-01 Required Fields Missing} \newline
1. The system displays the message ``Portfolio title is required.'' \newline
2. The use case ends.} \\ \arrayrulecolor{white}\cline{2-4}\arrayrulecolor{black}
& \multicolumn{3}{L{11.1cm}|}{\textbf{EX-02 Invalid Media Upload} \newline
1. The system displays the message ``Invalid file format or size limit exceeded.'' \newline
2. The use case ends.} \\ \arrayrulecolor{white}\cline{2-4}\arrayrulecolor{black}
& \multicolumn{3}{L{11.1cm}|}{\textbf{EX-03 Database or Storage Failure} \newline
1. The system displays the message ``Unable to create portfolio. Please try again later.'' \newline
2. The use case ends.} \\ \hline
Priority: & \multicolumn{3}{L{11.1cm}|}{High} \\ \hline

Description: & \multicolumn{3}{L{11.1cm}|}{Allows a freelancer to remove a portfolio from their profile by performing a soft delete operation.} \\ \hline
Preconditions: & \multicolumn{3}{L{11.1cm}|}{
\textbf{PRE-1} The freelancer is authenticated and logged in. \newline
\textbf{PRE-2} The freelancer is the owner of the portfolio. \newline
\textbf{PRE-3} The portfolio exists and is not already deleted.
} \\ \hline
Post-conditions: & \multicolumn{3}{L{11.1cm}|}{
\textbf{POST-1} The portfolio is soft-deleted by updating the deleted\_at field. \newline
\textbf{POST-2} The portfolio is no longer visible in the portfolio list.
} \\ \hline
Normal Flow: & \multicolumn{3}{L{11.1cm}|}{
\textbf{A. Delete Portfolio} \newline
1. Freelancer clicks the ``Delete'' option next to a portfolio. \newline
2. The system displays a confirmation dialog. \newline
3. Freelancer clicks the ``Confirm'' button. \newline
4. The system performs a soft delete by updating the deleted\_at field for the portfolio record. \newline
5. The system displays the message: ``Portfolio deleted successfully.'' \newline
6. The system removes the portfolio from the visible list.
} \\ \hline
Alternative Flows: & \multicolumn{3}{L{11.1cm}|}{\textbf{A.3 Cancel Deletion} \newline
1. Freelancer clicks the ``Cancel'' button in the confirmation dialog. \newline
2. The system closes the dialog. \newline
3. Return to step A.1.} \\ \hline
Exceptions: & \multicolumn{3}{L{11.1cm}|}{\textbf{EX-01 Portfolio Not Found} \newline
1. The system displays the message ``Portfolio not found.'' \newline
2. The use case ends.} \\ \arrayrulecolor{white}\cline{2-4}\arrayrulecolor{black}
& \multicolumn{3}{L{11.1cm}|}{\textbf{EX-02 Database Connection Failure} \newline
1. The system displays the message ``Unable to delete portfolio. Please try again later.'' \newline
2. The use case ends.} \\ \hline
Priority: & \multicolumn{3}{L{11.1cm}|}{Medium} \\ \hline
Frequency of Use: & \multicolumn{3}{L{11.1cm}|}{Low} \\ \hline
Business Rules: & \multicolumn{3}{L{11.1cm}|}{
BR-PORT-07: Portfolio deletion must be a soft delete (updating the deleted\_at column). \newline
BR-PORT-08: Soft-deleted portfolios must not be displayed.
} \\ \hline
Other Information: & \multicolumn{3}{L{11.1cm}|}{Soft-deleted portfolios can potentially be restored by the freelancer if an archive page is implemented.} \\ \hline
Assumptions: & \multicolumn{3}{L{11.1cm}|}{The soft delete does not immediately remove associated media files from storage.} \\ \hline
\end{longtable}
