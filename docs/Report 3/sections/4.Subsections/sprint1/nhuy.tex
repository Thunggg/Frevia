\subsubsection{UC-07.01 -- View Freelancer Profile}
\textbf{Function Trigger:} Open freelancer profile.

\textbf{Function description:} Display profile information.

\textbf{Precondition:} The target freelancer/\allowbreak{}client resource exists. This read endpoint is public and does not require a JWT.

\end{enumerate}

\textbf{Interface/\allowbreak{}API mapping:} GET /\allowbreak{}profiles/\allowbreak{}:id. The UI displays the returned state or error.

\subsubsection{UC-08.02 -- Add Freelancer Skill}
\textbf{Function Trigger:} Choose catalog skill and proficiency; Add.

\textbf{Function description:} Insert skill into local list sorted by name; close editor.

\textbf{Precondition:} Freelancer is authenticated with an active session and permission for the endpoint. Required records and valid input are prepared for the success path.

\textbf{Process and validation:}
\begin{enumerate}
\item Retrieve the freelancer profile and account roles; reject a missing or non-freelancer account.
\item Find the active catalog skill by trimmed name, ignoring case; create a unique catalog entry if absent.
\item generate\allowbreak{}Unique\allowbreak{}Slug(trimmed); create catalog skill
\item Check whether this freelancer already has the selected catalog skill.
\item Create the freelancer-skill association with its proficiency level.
\item Insert skill into local list sorted by name; close editor
\end{enumerate}
\textbf{Alternative and exception handling:} UI preflight: search\allowbreak{}Skill\allowbreak{}Suggestions(name); require catalog match, integer proficiency, no local duplicate. API independently supports new catalog names.; [catalog skill does not exist -- direct API request]; [invalid token /\allowbreak{} session /\allowbreak{} role permission]: 401 /\allowbreak{} 403 error response; [request DTO /\allowbreak{} id validation fails]: 400 validation error; [profile missing OR user has no FREELANCER role]: 404 Freelancer\allowbreak{}Profile\allowbreak{}Not\allowbreak{}Found\allowbreak{}Exception; [stored owner user\allowbreak{}Id !=\allowbreak{} current\allowbreak{}User\allowbreak{}Id]: 403 Profile\allowbreak{}Forbidden\allowbreak{}Exception; [freelancer skill already exists]: 400 Freelancer\allowbreak{}Skill\allowbreak{}Duplicate\allowbreak{}Exception
