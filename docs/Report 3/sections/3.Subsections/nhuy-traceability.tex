\subsubsection{Schema and Identifier Conventions}
\begin{itemize}[leftmargin=1.7em,itemsep=2pt,topsep=3pt]
\item Profile.id identifies a general profile; User.id identifies an account. FreelancerProfile.id identifies the professional subtype. The three identifiers are not interchangeable.
\item Client public profile routes and favorite/follow targets use User.id. Freelancer public profile routes use Profile.id.
\item Contract URLs use the current slug route, while review APIs accept Contract.id.
\item Portfolio scope is title, description, technologies and projectUrl. Client company scope is companyName, companyDescription and website.
\item CV upload is PDF-only, maximum 10 MB. Avatar upload is JPEG/PNG/WebP, maximum 5 MB. Identity-document acceptance rules are recorded independently from these limits.
\end{itemize}
