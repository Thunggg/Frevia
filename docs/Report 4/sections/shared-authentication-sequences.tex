\paragraph{Authentication references}
The Verify JWT interaction in the use-case diagrams refers to the shared
authentication sequence in Figure~\ref{fig:tthuan-seq-verify-jwt}.
For public endpoints, token verification is optional. Missing or invalid
credentials allow Guest access without attaching an authenticated payload.
Permission checks and input validation follow the handler and guards of
each endpoint. Refresh and retry behavior is described where used.
