% ================= Milestone Management =================
\subsection{Milestone Management}

Milestone Management covers the UC-24 milestone lifecycle within an active
contract: listing milestones with financial metrics, viewing milestone details,
creating project milestones, modifying terms, deleting draft milestones,
requesting deliverable revisions, approving deliverables, and updating execution
progress.
