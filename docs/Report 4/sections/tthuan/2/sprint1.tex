\subsection{Verify JWT}

Verify JWT is the shared security guard protecting API endpoints across all modules.
Every incoming HTTP request with a Bearer token is intercepted, validated for cryptographic
signature and expiration time, and verified against the database to guarantee the associated
session remains active and has not been revoked.
